# NetSpeed Indicator — Hindi (hi-IN) Localized Listing Pack

> Localized listing for the **hi-IN** locale in Play Console. India is the primary market, so
> this is high-leverage. Key ASO reality: **many Indian users search in Latin/Hinglish**
> ("net speed meter", "internet speed") even on Hindi-set phones — so the localized long
> description **keeps the English keyword phrases alongside Devanagari**. Play indexes the
> localized long description, so both scripts earn ranking. Char limits enforced inline.

---

## 0. Decisions at a glance (hi-IN)

| Field | Value | Chars / limit |
|---|---|---|
| **Title** | `इंटरनेट स्पीड मीटर: लाइव` | 24 / 30 |
| **Short description** | see §2 | 70 / 80 |
| **Long description** | see §3 | 2,162 / 4000 |
| **Locale** | hi-IN | |

**Why a Devanagari title:** earns the India ranking advantage and reads native. But the Latin
keyword stays heavily in the long description and reviews, because real search traffic is mixed
script. Do **not** drop "internet speed meter" / "net speed" English phrases from the localized
listing.

---

## 1. Title — primary + variants (≤30 chars)

- **A (ship):** `इंटरनेट स्पीड मीटर: लाइव` — 24. Native Devanagari, head keyword.
- **B (test):** `नेट स्पीड मीटर: स्टेटस बार` — 26. "net speed meter: status bar".
- **C (Hinglish):** `Internet Speed Meter: हिंदी` — 27. Latin keyword + Hindi signal; catches mixed-script search.

Run as a Play store-listing experiment vs. the English title for hi-IN traffic; judge on install
conversion for India.

## 3. Long description (hi-IN, fully indexed; ≤4000 chars)

> repeat the primary keyword in both scripts (shown above the fold). ≈ 2,162 code points.

```

NetSpeed Indicator एक छोटा, बैटरी-फ्रेंडली इंटरनेट स्पीड मीटर है जो आपके स्टेटस बार को रियल-टाइम नेट स्पीड मॉनिटर बना देता है। देखें कि आपका Wi-Fi या मोबाइल डेटा कितनी तेज़ चल रहा है — उसी पल।

⚡ स्टेटस बार में लाइव स्पीड
• रियल-टाइम डाउनलोड + अपलोड स्पीड, स्टेटस-बार आइकन के रूप में
• स्टाइल चुनें: arrows, side-by-side, stacked, compact या auto
• यूनिट (KB/MB), बैकग्राउंड, टेक्स्ट रंग और आउटलाइन — आपका आइकन, आपके तरीके से
• स्मूद रीडआउट, ताकि नंबर स्थिर दिखे, झटके नहीं

🫧 फ़्लोटिंग स्पीड बबल
• किसी भी ऐप के ऊपर तैरता ड्रैग करने योग्य स्पीड चिप — गेम, वीडियो, ब्राउज़र

🏠 होम-स्क्रीन विजेट (5 स्टाइल)
• Hero banner, Dial, Rings, Pill और Weather विजेट
• एक टैप में "Add to Home screen" — कोई मेन्यू खोजना नहीं

📊 स्पीड + डेटा जानकारी

🎨 14 लाइव थीम × 6 कलर स्किन

• यह आपका डेटा कहीं भेज ही नहीं सकता — एक गारंटी जिसे आप जाँच सकते हैं

## 4. India keyword notes

- Keep BOTH scripts: Devanagari for native ranking + English/Hinglish phrases for real mixed-script
  search ("net speed meter", "internet speed", "status bar speed").
- India long-tail to retain in reviews + long desc: `internet speed meter hindi`,
  `net speed status bar`, `data usage daily`, `wifi signal meter`, `नेट स्पीड`, `इंटरनेट स्पीड मीटर`.
- Prompt Hindi-speaking reviewers to mention features in their own words — Devanagari reviews are
  indexed and lift hi-IN ranking.
